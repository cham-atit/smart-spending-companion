# 💰 Smart Spending Companion

A smart personal finance dashboard designed to help users understand their spending habits, monitor budgets, and make better financial decisions.

Smart Spending Companion is a React-based interactive prototype featuring expense tracking dashboards, financial insights, budget monitoring, and smart spending tools.

## ✨ Features

- **Dashboard** — Overview of spending activity and financial information.
- **Expense Insights** — Visual insights and spending breakdowns.
- **Smart Features** — Interactive tools designed to encourage better spending habits.
- **Stop Me Mode** — Budget awareness feature that warns users when spending approaches a defined limit.
- **Future Impact Predictor** — Estimates month-end spending using sample spending data.
- **Money Leak Detector** — Highlights potential spending patterns.
- **Subscription Tracker** — Displays subscription-related information.
- **Authentication UI** — Interactive login and registration interface.
- **Responsive Interface** — Designed for a modern dashboard experience.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/cham-atit/smart-spending-companion.git
```

Navigate to the project directory:

```bash
cd smart-spending-companion
```

Install dependencies:

```bash
npm install
```

### Run Locally

Start the Vite development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Build for Production

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.

Preview the production build locally:

```bash
npm run preview
```

## 📌 Project Status

This project is currently an interactive frontend prototype using simulated/sample data.

Authentication, spending information, and financial insights are intended for demonstration purposes. The project does not currently connect to a production banking service or persistent backend database.
